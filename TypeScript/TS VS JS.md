# TS VS JS

#### TS和JS的区别

TypeScript是JavaScript的超集。

而TypeScript和Javascript的区别可以从三方面总结：**类型系统原理**、**编译运行机制**、和**工程化影响**。

1. **类型系统**

   这是TS和JS最核心的区别。

   JS是**动态弱类型**，变量类型运行时才确定；而TS是**静态强类型**，它是JS的超集。并且TS是结构化类型系统，无需名字一样，只要有相同属性就能通过类型检查。（强类型和弱类型的核心区别在于是否允许**隐式类型转化**）

   JS的变量类型是在运行时确定的，而TS的变量类型在编译时确定。

   此外，TS 引入了**泛型、接口、枚举**等 JS 不具备的高级特性，极大地增强了抽象能力。

2. **运行机制**

   - **JavaScript:** 可以直接在浏览器、Node.js 环境中运行。
   - **TypeScript:** **不能直接运行**。它必须通过编译器（Compiler）被“翻译”（编译/转译）成 JavaScript 后，才能在浏览器或服务器上运行。

   而TS编译成JS后会擦除变量类型，**类型擦除**意味着 TypeScript 的类型定义只是给编译器看的“注释”。一旦编译器（tsc）工作结束，这些东西就会被全部删掉，只留下纯粹的 JavaScript 逻辑。

3. **工程化影响**

   -  开发体验上：TS 提供了极强的智能感知（IntelliSense）和安全的重构能力。
   - 维护成本上：虽然 TS 增加了初期的编写成本和构建配置复杂度，但它消除了绝大多数 undefined 引用错误，使得代码库在长期迭代中更加健壮，特别适合多人协作。

   总结来说，JS 适合快速原型开发和小型脚本，而 TS 是构建大规模、高可维护性前端应用的企业级标准。



#### TS相对于JS的优势

1. **静态类型检查：**这是TS最本质的优势，通过类型检查，我们能在运行前就发现绝大多数拼写错误或类型不匹配的问题。
2. **开发体验：**TS 提供了极强的**智能感知（IntelliSense）**。编辑器能精准地提示属性、方法和参数，这比在 JS 里靠记忆或查文档要快得多。
