# 项目难点及如何解决的

#### 1. Collapse组件的折叠动画

一开始是尝试使用原生CSS的`transition`属性实现折叠的平滑效果，但由于`collapse-item`的高度是不确定的`auto`，原生CSS无法实现`height: 0`到`auto`的变化。

**核心痛点：**

CSS 的 `transition` 属性不支持从 `height: 0` 到 `height: auto` 的过渡动画。 浏览器无法计算 auto 的具体高度，导致直接写 CSS 只有突变效果，没有动画。

于是尝试了用**`transition: scaleY()`**实现，代码如下：

```CSS
.collapse-content {
  /* 1. 设置变换原点为顶部，这样折叠时会向上收起 */
  transform-origin: top;
  
  /* 2. 添加过渡动画 */
  transition: transform 0.3s ease-in-out;
}

/* 收起状态 */
.collapse-content.closed {
  /* 垂直方向缩放到 0，元素会被压扁 */
  transform: scaleY(0);
  
  /* 尽管视觉上没了，但它可能还占位，通常需要配合 max-height: 0 或 height: 0 来消除占位 */
  height: 0; 
  overflow: hidden;
}

/* 展开状态 */
.collapse-content.open {
  /* 恢复原始比例 */
  transform: scaleY(1);
  height: auto; 
}
```

但这样的话会拉伸内部的字体和图片，视觉效果严重失真。

**最终方案：**

采用Vue原生`transition`组件配合CSS的`transition`属性实现。

核心思路就是利用 JavaScript 钩子，将 CSS 无法进行动画过渡的 `auto` 高度，转化为具体的 `scrollHeight` 像素值，赋予动画明确的起始点和结束点，并在动画结束后将控制权交还给 CSS 以保持响应性。

如果最后不清楚内联样式，`height`会使得丢失响应式，`overflow: hidden`则会导致样式显示不全。

```vue
<script>
const transitionEvent: Record<string, (el: HTMLElement) => void> = {
  beforeEnter (el) {
    el.style.height = '0px'
    el.style.overflow = 'hidden'
  },
  enter(el) {
    el.style.height = `${el.scrollHeight}px`
  },
  afterEnter(el) {
    el.style.height = ''
    el.style.overflow = ''
  },
  beforeLeave(el) {
    el.style.height = `${el.scrollHeight}px`
    el.style.overflow = 'hidden'
  },
  leave(el) {
    el.style.height = '0px'
  },
  afterLeave (el) {
    el.style.height = ''
    el.style.overflow = ''
  }
}
</script>

<style>
.slide-enter-active, .slide-leave-active {
  transition: height 0.3s ease-in-out
}
</style>
```

利用`.scrollHeight`拿到元素高度并显示赋给`height`属性使得`height`为一个确认值能够实现CSS的`transition`效果。

`transition`属性的简写表示：要应用过渡效果的 CSS 属性，过渡效果的持续时间，过渡效果的加速曲线，过渡效果的延迟时间。
