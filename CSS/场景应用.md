# 面试常考CSS场景应用

核心都是利用CSS样式布局完成指定场景。

1. #### **画一个自适应正方形**

自适应形状的实现思路和响应式布局有异曲同工之妙，都是利用相对单位（如百分比、`vw`）来实现自适应。

**（1）利用`vw`**

`vw`是相对于视口宽度来计算的。

可以直接让宽高都**相对视口宽度**来计算：

```css
.square {
    width: 25vw;
    height: 25vw;
    background-color: red;
}
```

那么还可以用**百分比**来实现自适应，但百分比是相对于父元素的宽/高计算的，由此则需要**`padding-top`**来实现正方形：

```css
.square {
    width: 25%;
    padding-top: 25%;
    background-color: red;
}
```

padding是相对于父元素宽度计算的，所以可以利用padding把盒子高度撑开实现正方形。

同理也可以通过**margin+伪元素**实现：

```css
.square {
    width: 25%;
    overflow: hidden;
    background-color: red;
}

.suqare::after {
    content: '';
    display: block;
    margin-top: 100%; // 父元素宽度的100%
}
```

其实原理是利用标准盒模型盒子宽度不包括margin实现的，通过一个无内容的子盒子将父盒子（也就是目标盒子）撑开来实现自适应正方形。



2. #### **用CSS画三角形**

绘制三角形的核心是利用边框**border**属性。当宽高都为0四条边框都存在时实际的效果是四个全等三角形拼接而成的正方形。

**（1）普通三角形**

可以直接按照宽高为0+四条边框，然后想要哪个朝向的三角就设置哪个三角有颜色，其他三角全为透明：

```css
div {
    width: 0;
    height: 0;
    border-bottom: 20px solid red;
    boder-top: 20px solid transparent;
    boder-left: 20px solid transparent;
    boder-right: 20px solid transparent;
}
```

或者不设置`border-top`也可以出现三角形，反正原理就是通过边框的显示隐藏实现三角形。

**（2）直角三角形**

和上述原理都一致，简单的几何问题。

```css
div {
    width: 0;
    height: 0;
    border-bottom: 20px solid red;
    boder-top: 20px solid transparent;
    boder-left: 20px solid transparent;
    boder-right: 20px solid red;
}
```

突然想到其实最原始的四个小三角形就是四个等腰直角三角形。

**（3）等边三角形**

在掌握了基本原理后不同类型的三角形其实都是几何问题了。

已知等边三角形的高是底的√3：

```css
div {
    width: 0;
    height: 0;
    border-left: 50px solid transparent;
    border-right: 50px solid transparent;
    border-bottom: 86.6px solid red; // 50 * √3 = 86.6
}
```
