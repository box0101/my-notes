# `Watch` VS `watchEffect`

**官方定义**

- **`watchEffect()`**

  立即运行一个函数，同时响应式地追踪其依赖，并在依赖更改时重新执行。

  基本语法：`watchEffect(effect => void, options)`

  第一个参数是回调函数，第二个参数可以调整副作用刷新时机。

- **`watch()`**：

  侦听一个或多个响应式数据源，并在数据源变化时调用回调函数。默认是懒侦听，仅在侦听源发生变化时执行回调函数。

  **基本语法：**`watch(sources, callback, options)`

  第一个参数是侦听的数据源，第二个参数是回调函数，回调函数会携带变化前和变化后的数据，第三个参数是可选的其他配置，例如`flush`、`immediate`等。
  
  值得注意的是，`sources`如果是不具备响应式的普通变量，需要以箭头函数传入，Vue 会重新调用这个函数获取最新值，如果直接传入的话就只能获取第一次传入的值，无法追踪变化。

**与`watchEffect()`相比，`watch()`使我们可以：**

- 懒执行副作用。
- 更加明确应该由哪个状态触发侦听器重新执行。
- 可以访问所侦听状态的前一个值和当前值。



**面试常考：二者区别？**

1. **追踪方式：**

   `watchEffect()`监听的是一个函数，Vue会在执行它时记录读取的所有响应式属性作为依赖，任一依赖发生变化时都会触发侦听器重新执行该函数。

   `watch()`直接监听想要监听的数据源source，只有source发生变化时才会触发回调函数，触发条件更可控，开销更小。

2. **触发时机：**

   `watchEffect()`在注册时就会立即执行一次。

   `watch()`则默认不执行首次回调，但可以设置`options`为`{immediate: true}`来让它首次就执行回调。

3. **访问旧值：**

   `watch()`可以访问到source的前一个值和当前值。

4. **深度监听：**

   `watch()`可以通过设置{ deep: true }实现深度监听，即监听对象里的属性，`watchEffect()`则自动跟踪读取到的那部分属性。
