# 组件通信

### **1. props/$emit**

`props`父传子，`$emits`子传父。

- #### **父传子**

**Vue3`setup`语法糖**下的写法：

父组件在子组件上动态绑定响应式变量，子组件通过`defineProps`拿到父组件传来的数据。

```vue
<!-- Parent.vue -->
<template>
  <Child :title="pageTitle" :count="n" />
</template>

<script setup>
import { ref } from 'vue'
import Child from './Child.vue'
const pageTitle = 'hello'
const n = ref(5)
</script>

<!-- Child.vue -->
<script setup>
const props = defineProps({
  title: String,
  count: Number
})
</script>

<template>
  <div>{{ title }} — {{ count }}</div>
</template>
```

**Vue2 Options API**的写法：

子组件export default把自己暴露给父组件同时告诉父组件自己能接收哪些数据。

```vue
// 父组件
<template>
    <div id="father">
        <son :msg="msgData" :fn="myFunction"></son>
    </div>
</template>

<script>
import son from "./son.vue";
export default {
    name: father,
    data() {
        msgData: "父组件数据";
    },
    methods: {
        myFunction() {
            console.log("vue");
        }
    },
    components: {
        son
    }
};
</script>

// 子组件
<template>
    <div id="son">
        <p>{{msg}}</p>
        <button @click="fn">按钮</button>
    </div>
</template>
<script>
export default {
    name: "son",
    props: ["msg", "fn"]
};
</script>
```

- #### **子传父**

**Vue2**写法：

子组件`$emit`发送自定义事件，父组件`@事件名`监听。

```vue
// 子组件
<script>
export default {
  props: ["msg"],
  methods: {
    sendValue() {
      this.$emit("update", "hello")
    }
  }
}
</script>

<template>
  <button @click="sendValue">按钮</button>
</template>

// 父组件
<son :msg="msgData" @update="handleUpdate" />

methods: {
  handleUpdate(value) {
    console.log("子组件传来的值", value)
  }
}
```

**Vue3 setup**语法糖：

Vue3不用加`$`，并且直接用`defineEmits`定义事件，`emit("事件", value)`将数据发送给父组件，父组件用`@事件名`或`v-on:update`接收。

```vue
// 子组件
<template>
	<button @click="sendValue">
        click it
    </button>
</template>

<script setup>
    const emit = defineEmits(["update"])
    
    function sendValue (value) {
        emit("update", value)
    }
</script>

// 父组件
<son :update="handleUpdate"></son>
```

### 2. 依赖注入（provide/inject）

此方法适用于**跨层级透传**。

**`provide()`函数**为组件后代提供数据：

```vue
<script setup>
import { provide } from 'vue'

provide(/* 注入名 */ 'message', /* 值 */ 'hello!')
</script>
```

provide()有两个参数：第一个是注入名，可以是字符串或Symbol，后代组件会用注入名来查找期待注入的值；第二个是提供的值，可以是任意类型。

> 除了在一个组件中提供依赖，还可以在整个应用层面提供依赖：
>
> https://cn.vuejs.org/guide/components/provide-inject

使用**`inject()`注入**上层组件提供的数据：

```vue
<script>
import { inject } from 'vue'
    
const msg = inject('message')
</script>
```

如果有多个父组件提供了相同键的数据，注入将解析为组件链上最近的父组件所注入的值。

### 3. ref/$refs

通过模板引用实现父子组件间的通信：

```vue
// 子组件 Child.vue
<script>
import { ref } from 'vue'
const count = ref()

defineExpose({
    count
})
</script>

// 父组件
<template>
	<Child ref="childCount"></Child>
	<button @click="addChildCount">
        add
    </button>
</template>

<script>
import Child from 'Child.vue'

const childCount = ref(0)
function addChildCount () {
    console.log(childCount)
}
</script>
```

### 4. eventBus事件总线

`eventBus`事件总线用于父子组件、非父子组件之间的通信：

```javascript
// 创建事件中心管理组件之间的通信
// event-bus.js
import Vue from 'vue'
export const EventBus = new Vue()

// 在组件内发送事件
EventBus.$emit('hello', 'hi')

// 在组件内接收事件
EventBus.$on('hello', (msg) => {
    console.log(msg)
})
```

但Vue3官方不推荐EventBus，更推荐使用mitt这个超轻量库实现同样效果。



**总结**

1. 父子组件间通信：props/$emit、ref/$refs、provide/inject
2. 任意组件：eventBus
