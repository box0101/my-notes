# Vue VS React

#### 官方定义
- **Vue：**是一个用于构建用户界面的 **JavaScript *渐进式框架***，基于 HTML、CSS 和 JavaScript 构建，帮助高效开发用户界面。

- **React：**React 应用程序是由**组件**组成的。一个组件是 UI 的一部分，它拥有自己的逻辑和外观。

一个说自己是框架一个说自己是库，但二者最终的效果其实是类似的，区别就在于Vue官方提供了从<u>声明式渲染</u>到构建工具一系列东西，而React官方只提供了React.js这一个库，其他都是从社区第三方集成整合成一套方案。

[^渐进式框架]: Vue被称之为渐进式框架，是因为它的核心能力可以逐步按需引入。开发者可以从最基础的视图层能力开始例如模版渲染和响应式数据绑定，随着应用规模扩大再逐步引入路由、状态管理等官方生态。因此Vue的设计强调按需使用和渐进增强。相对的，React本质上是UI库，很多功能需要依赖第三方组合，框架并非天然渐进式。



#### **声明式渲染**：

声明式渲染是指只操作数据而不操作视图，数据就自动映射到视图上。当设定好数据与视图的映射关系后操作数据就是声明式编程。

与**响应式数据**不同的是，声明式渲染强调的是从数据反应到视图上的机制，而响应式数据强调的是变化，要在数据发生改变时视图也相应做出改变。



#### 模板和JSX：

那么要如何设定数据到视图的映射关系，这就要说到模板和JSX——Vue使用模板而React使用JSX。

- **模板**

根据Vue官方文档可知，Vue使用一种基于**HTML**的模板语法，使得能够声明式地将组件实例的数据绑定到呈现的DOM上。在底层机制中，Vue会将模板编译成高度优化的JS代码。

同时文档中还注明：

> 如果你对虚拟 DOM 的概念比较熟悉，并且偏好直接使用 JavaScript，你也可以结合可选的 JSX 支持[直接手写渲染函数](https://cn.vuejs.org/guide/extras/render-function.html)而不采用模板。但请注意，这将不会享受到和模板同等级别的编译时优化。

- **JSX**

官方定义：JSX是**JavaScript**语法扩展，可以在JavaScript文件中书写类似HTML的标签，它最终会被编译成普通JS调用。

**那么为什么Vue默认推荐使用模板？**

1. **模板更贴近实际的HTML。**这使得可以更让方便地重用一些HTML片段，能够带来更好的可访问性体验、能更方便地使用CSS应用样式，并且更容易设计师理解和修改。
2. 由于其确定的语法，**更容易对模板做静态分析**。这使得Vue的模板编译器能够应用许多编译时优化来提升虚拟DOM的性能表现。



#### 组件化：

组件化是编写复杂应用的又一基石特性。

**Vue**的组件更像一个对象，无论是Vue2还是Vue3都是填充组件对象的内容，扩充组件对象的功能。

**React**分函数组件和类组件。函数组件更符合React的函数式思维，以UI=fn(State)作为自己的主线，其他都是副作用。



#### 总结

**相同之处：**

1. 都专注于**视图构建**，采用声明式渲染，将其他功能例如路由和状态管理交给相关的库。
2. 都采用**组件化应用**，提高复用性。
3. 都使用**虚拟DOM**而不直接操作DOM元素，提高性能。
4. 都有**props**的概念，允许组件间通信。

**不同之处：**

1. **数据流**

Vue默认支持数据双向绑定而React则提倡单向数据流。

Vue内置了v-model语法糖实现数据的双向绑定，同时还可以通过props/emits实现父子双向通信；而React不是不支持数据双向绑定，而是更鼓励单向数据流，这也与它的函数式思维有关，修改UI就必须通过 UI = f(State) 的方式，保证数据来源透明。

2. **虚拟DOM**

Vue在渲染过程中会跟踪每一个组件的依赖关系，当有更新时不需要重新渲染整个组件树。

而React每当应用的状态发生改变时全部子组件都会被重新渲染。

3. **组件化**

Vue和React最大的不同是实现声明式渲染时的语法不同。

Vue采用近似常规HTML的模板语法，而React则采用JavaScript的扩展语法JSX，把HTML结构直接写在JavaScript中，逻辑和结构混合。

4. **响应式机制**

Vue3使用Proxy（Vue2使用defineProperty）来劫持数据对象，在数据发生变化时只更新相关节点。

React则是每次状态改变时就会重新执行整个组件函数以生成新的虚拟DOM树，且React无法知道是哪些字段具体变化，因为它只能比较引用。

5. **构建工具**

二者各自有自己的构建工具：

Vue：create-vue+Vite（Vue3更推荐）、Vue CLI

React：Vite+Next.js



### 常考面试题

#### Vue和React区别？

1. **设计理念与编程范式**
   - React偏向函数式编程的思想，强调 UI = fn(state) 的思想，认为 UI 是数据的映射，因此也采用 All in JS的思想，通过 JSX 的语法用 JavaScript 描述 UI。
   - Vue则是渐进式框架，采用基于 HTML 的模版语法和单文件组件模式，更接近传统的各司其职的前端开发方式。
2. **数据流与响应式原理**
   - Vue 原生支持基于 Proxy 的响应式拦截，在数据变化时只更新相关节点，并且 Vue 原生支持数据的双向绑定，提供了 v-model 语法糖和 props/emits 实现父子双向通信。
   - React 强调数据不可变，每次状态改变时都会重新执行整个组件函数实现数据更新，并且 React 更提倡单向数据流，这也与它的函数式编程思想有关，只有单向的数据流才能保证数据来源透明。
3. **渲染机制**
   - Vue 在模版编译和运行时会进行精确的依赖收集，一旦数据改变能精确定位到需要更新的组件甚至具体的 DOM 节点。
   - React 在组件状态变化时将该组件及其所有子组件重新执行一遍，生成新旧虚拟 DOM 树进行 Diff 找出差异。
4. **生态建设**
   - Vue 是一个用于构建用户界面的渐进式框架，Vue 官方提供了从声明式渲染到构建工具的一系列“全家桶”。
   - React 本质上只是一个 UI 库，其他都是从社区整合而成的一套方案。
