# Promise

#### **官方定义**

**`Promise`** **对象**表示异步操作最终的完成（或失败）以及其结果值。

一个 `Promise` 必然处于以下几种状态之一：

- 待定（pending）：初始状态，既没有被兑现，也没有被拒绝。
- 已兑现（fulfilled）：意味着操作成功完成。
- 已拒绝（rejected)：意味着操作失败。

Promise 的状态具有不可逆性，只能从 pending 变为 fulfilled 或 rejected，一旦状态改变就会固化，永远不会再改变。

------

Promise 是 JavaScript 中解决异步编程的一种对象，它代表了一个异步操作的最终完成（或失败）及其结果值。



**`Promise`的静态方法：**

- `Promise.resolve()`/`Promise.reject()`：

  快速创建一个状态为成功或失败的 Promise 对象。

- `Promise.all()`：

  - 并发执行。全部成功才成功，返回一个数组包含所有结果；有一个失败整个`all`立即失败，并返回第一个失败原因。
  - 使用场景：
    - 强依赖关系：需要多个接口的数据全部到齐后才能渲染页面。
    - 批量操作：同时上传多张图片，必须全部上传成功才算成功。

- `Promise.race()`：

  - 返回第一个执行完成的 Promise 的结果（无论是成功或失败）。一旦有一个结果出来剩下的 Promise 仍会继续执行但是结果会被丢弃。
  - 使用场景：
    - 请求超时控制：将一个网络请求和一个 `setTimeout` 放在一起赛跑。如果定时器先跑完，就判定为超时。
    - 资源竞争：从多个镜像服务器请求同一个资源，谁快用谁的。

- `Promise.allSettled()`：

  - 等待所有 Promise 执行完成，返回一个对象数组记录所有的状态和 `value` 或 `reason`。永远不会进入 `catch` 状态，除非传入的参数不可迭代。
  - 使用场景：
    - 互不依赖的任务：比如同时发起 5 个不相关的统计接口，需要知道哪些成功了，哪些失败了，而不是因为一个失败就放弃获取其他数据。

- `Promise.any()`：

  - 只要有一个 Promise 成功就返回那个成功的结果，只有当所有 Promise 都失败时，才会进入失败状态，抛出一个 `AggregateError`（包含所有失败原因）。与 `.race()` 不同的是 race 关注的是第一个执行完成的无论成功与否，any 关注的是第一个成功的。
  - 使用场景：
    - 多源容灾：同时请求三个库的 CDN，只要有一个返回了资源即可使用，除非三个都挂了才报错。

  

**`Promise`的实例方法：**

- `p.then(onFulfilled?, onRejected?)`：

  then的两个参数都是可选的，会在p成功时调用`onFulfilled`，在p拒绝时调用`onRejected`。该方法返回的是一个新的Promise实例。

- `p.catch(onRejected)`：

  用于指定发生错误时的回调，其实就是 `.then(null, onRejected)` 的语法糖。

- `p.finally(onFinally)`：

  无论成功或失败都会执行。
