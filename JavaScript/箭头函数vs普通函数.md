# 箭头函数 VS 普通函数

#### （1）语法更简洁
直接用箭头连接参数和大括号括起来的函数体。

如果只有一个参数可以不写小括号，若没有参数就只写一个小括号。

#### （2）没有自己的this
箭头函数继承自己作用域上一层的 `this` ，没有自己的 this 。

所以也可以知道箭头函数的 this 不会被 `apply()`, `call()`, `bind()` 改变。

#### （3）不能用作构造函数
**`new` 一个函数的过程：**

- 创建一个对象
- 将对象的`.__proto__`指向构造函数的 `prototype` 属性（也就是将构造函数的 this 指向对象）
- 为对象添加属性和方法
- 返回对象

如果 new 了一个箭头函数，会在第二步就报错，因为箭头函数没有 `prototype` 属性，也没有自己的 this 。

#### （4）没有 arguments 对象
arguments 是函数自动创建的**类数组**对象，里面包含了调用函数时传入的所有实参。箭头函数没有自己的arguments对象，在箭头函数中访问arguments实际上获得的是它外层函数的arguments值。

**剩余参数（`...args`）和 `arguments`对象之间的区别：**

- arguments不是真正的数组，而剩余参数是数组实例。
- 在非严格模式且参数简单的函数中，`arguments` 对象会将索引值与参数值同步。当具名参数被重新赋值时，剩余参数数组的值永远不会更新。
- 剩余参数将所有*额外*参数打包为单一数组，但不包含任何在 `...restParam` *之前*定义的具名参数。`arguments` 对象则包含所有参数（包括 `...restParam` 数组中的参数），这些参数被打包为类数组对象。



#### 普通函数的this指向

一般指向**调用函数的对象**，如果是直接调用函数则指向**全局对象（浏览器是`window`，严格模式下是`undefined`**。如果是构造函数调用则是指向新创建的实例对象，`call`、`apply`、`bind`可以显示指定绑定的对象。



#### this 代码输出题注意点

- (function() {... return function() {}})() 形式的是立即执行函数，在声明时立即调用，将返回的函数赋给对象。
- 参数伪数组 (arguments)：如果通过 arguments[0]() 调用，this 会指向 arguments 这个伪数组
- this绑定的优先级：**new 绑定 > 显式绑定（call、apply、bind） > 隐式绑定（对象调用） > 默认绑定（指向全局对象）。**
- 如果指向 null/undefined，在严格模式下指向什么就是什么，在非严格模式下都会被指向 window。
- 对象不构成单独的作用域
